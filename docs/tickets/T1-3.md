Commands: `python3 tools/ci/check_linux_package.py`; `swift test --package-path Packages/LyricClipsKit --jobs 4`.

Design limits: one store instance owns each root; no cross-process locking or hostile concurrent filesystem mutation guarantee. Foundation path checks protect stored static paths and symlinks, not an attacker swapping paths between check/open. The app sandbox and exclusive store ownership are prerequisites. Tests simulate interruption at the stage/publication boundary, not physical power loss. Orphan staging files are ignored, not used as backups. Imported metadata must come from LCAudio; the pure store does not decode media. Synthetic `abc` bytes test storage/hash behavior, not audio validity. Full audio hashes are checked on load/list; large-library performance remains to be measured.

Mac steps: rerun swift test; inspect `isExcludedFromBackup` on Projects and each project directory; verify Application Support path handling and atomic replacement on APFS. The Apple branch is compiled conditionally and has not been executed here.
