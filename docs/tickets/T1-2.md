## Implementation choices and limits

Models expose immutable properties so direct mutation cannot bypass validation. TimingEditor will construct validated replacement values. Optional start/end support incomplete tap timing. ASRLanguage lives in LCCore to prevent a dependency cycle. There is no undocumented schema migration, downloaded model, checkpoint system, inference implementation, or ProjectStore here. Path validation is lexical; filesystem containment and symlinks belong to T1-3. Dates follow the spec's Foundation ISO-8601 strategy (second precision); audio times retain Double precision.
